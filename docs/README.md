# ControlWatch Documentation

ControlWatch is a read-only Stellar and Soroban control-monitoring CLI. It
records immutable snapshots, compares measured configuration, and attaches
available on-chain evidence.

Use the navigation to start with the [Quickstart](quickstart.md), or jump to
the [CLI reference](cli.md) and [detector reference](detectors.md).

ControlWatch does not sign or submit transactions and does not provide a legal,
compliance, or security conclusion.
